# first_test

Projet Flutter réalisé pour démontrer les concepts fondamentaux de l’architecture des widgets et des différentes approches de gestion d’état (State Management).

## Démonstrations importantes

Les commits suivants correspondent aux principales démonstrations du projet :

| Démonstration | Commit |
|--------------|--------|
| Démonstration 1 – StatelessWidget (Widget immuable) | `31a21a14d4f850ed59b4e3aec7815320e0d9545e` |
| Démonstration 2 – StatefulWidget | `d4748144093f89e594df8d91f0c54983ff79d94b` |
| Démonstration 3 – Cycle de vie d'un StatefulWidget et de son objet `State<T>` | `2a5d952690adb376112e7ac0b9c72fac9af421fe` |
| Démonstration 4 – Provider | `f1ad78feae2a259b8295b742cb36f007d91b8414` |
| Démonstration 5 – BloC | `45497646c9f32ad2bb448effabfc742c5111a7c3` |

Chaque commit représente une étape importante de l'évolution du projet et peut être consulté indépendamment afin de comprendre l'implémentation de chaque concept.
